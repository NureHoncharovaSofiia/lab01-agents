## 2. Призначення

Предметна область — класичні патерни проєктування GoF, варіант № 1. Агент пояснює призначення окремих патернів і порівнює їх українською. Для пошуку агент може звернутися до локального довідника та повідомити, якщо запису немає. Довідник містить сім патернів. Запити з інших предметних областей виходять за межі призначення агента.

- «Що таке патерн Observer?»
- «Порівняй Adapter і Decorator».
- «Чим відрізняються Singleton, Factory Method і Abstract Factory?»

## 3. Архітектура

| Дія | Аргументи | Детермінована? | Змінює середовище? |
|---|---|---|---|
| `lookup_pattern` | `name` — назва патерну | Так | Ні |
| `finish` | `answer` — текст відповіді | — | Ні |

У власному циклі `finish` завершує виконання, а `MAX_STEPS = 6` обмежує кількість кроків. Невідома дія стає спостереженням `ERROR`. У контрольному сценарії після такого спостереження агент завершився на другому кроці. У сценарії з повторюваним пошуком агент зупинився після шостого кроку з причиною `max_steps`. Довідник повертає `NOT_FOUND`, коли назва відсутня.

## 5. Запуск

У каталозі `manual-agent`:

```bash
uv run python main.py "Що таке патерн Observer?" --mode agent --model gemini-3.5-flash-lite
```

У каталозі `adk-agent` запустіть `agents-cli playground`. В іншому терміналі в тому самому каталозі виконайте:

```bash
agents-cli run "Що таке патерн Observer?" --url http://127.0.0.1:8080 --mode adk --app-name app
```

Змінна оточення для доступу до Gemini API — `GEMINI_API_KEY`.

## 6. Результати експерименту

| Метрика | One-shot | Власний агент | ADK-агент |
|---|---:|---:|---:|
| Середня правильність за шкалою 0–2 | 1,6 | 2,0 | 1,8 |
| Галюцинація на запиті D | Так | Ні | Ні |
| Середня кількість викликів LLM | 1,0 | 1,6 | Потрібні події п’яти сесій |
| Середня кількість пошуків | 0,0 | 0,6 | 1,4 |
| Середній час, с | 1,58 | 1,96 | 12,33 (повний час CLI) |

За запит D one-shot отримав 0 балів, бо назвав Flux Capacitor архітектурним патерном. За запит E ADK отримав 1 бал, бо правильно описав GoF, але помилково заявив, що довідник охоплює більшість патернів. У решті випадків відповіді отримали по 2 бали. Кількість викликів інструмента ADK зафіксовано в CLI. Один виклик LLM може ініціювати кілька пошуків.

## 7. Відомі обмеження та ризики

- Агент може відповісти без пошуку. У власному циклі так сталося у запитах C, D та E.
- Довідник виконується локально, а генерація залежить від мережі та доступності Gemini API.
- Виміряний час ADK охоплює запуск CLI й обмін із локальним сервером. В експерименті виконано по одному запуску для кожної пари «запит — система».
